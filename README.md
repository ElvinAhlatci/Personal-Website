# Personal Website

## Proje Hakkında

Bu proje, HTML ve CSS kullanılarak geliştirilmiş kişisel bir web sitesi tasarımıdır. Sayfada kişisel bilgiler, eğitim hedefi ve GitHub profil bağlantısı yer almaktadır.

## Projenin Amacı

Bu proje, HTML ve CSS kullanarak temel bir kişisel web sitesi oluşturmayı ve web sayfasının görünümünü CSS ile düzenlemeyi öğrenmek amacıyla hazırlanmıştır.

## Özellikler

- Kişisel isim ve soyisim gösterimi
- Profil fotoğrafı
- Yönetim Bilişim Sistemleri adayı bilgisi
- Kısa kişisel tanıtım yazısı
- GitHub profil bağlantısı
- Sabit sol menü tasarımı
- Profil fotoğrafı için yuvarlak görünüm
- Özel yazı tipi kullanımı

## Kullanılan Teknolojiler

- HTML
- CSS
- Font Awesome
- Google Fonts

## Kullanılan Konular

- HTML sayfa yapısı
- CSS ile sayfa tasarımı
- Flexbox
- Position kullanımı
- Font ve yazı stillendirme
- Renk ve arka plan düzenlemeleri
- Görsel ekleme ve düzenleme
- Link kullanımı
